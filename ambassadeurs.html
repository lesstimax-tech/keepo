Questions fréquentes

Faut-il beaucoup d'abonnés ?

Non, aucun minimum. Le programme est ouvert à tous les majeurs : créateurs, étudiants, commerciaux, amis de commerçants… Un seul commerce abonné vous rapporte déjà 30 €.

Quand est-ce que je touche ma prime ?

La prime de 30 € est gagnée quand le commerce a payé son 2ᵉ mois d'abonnement (ou dès son paiement s'il choisit l'annuel). Les virements partent une fois par mois, dès que vous avez au moins 50 € à recevoir. Tout est suivi dans votre espace.

Comment le commerce utilise-t-il mon code ?

Le plus simple : votre lien keepo.eu/a/VOTRECODE, qui remplit le code tout seul. Sinon, le commerçant le tape à l'inscription, ou plus tard dans son espace, tant qu'il n'a pas encore payé son abonnement.

Y a-t-il une limite ?

Aucune limite de nombre : 30 € par commerce abonné grâce à vous. Une seule prime par commerce.

Dois-je déclarer ces gains ?

Oui : les primes sont des revenus, à déclarer selon votre situation. Si vous en touchez régulièrement, le statut de micro-entrepreneur est souvent le plus simple. Pour être payé, vous renseignez un IBAN à votre nom dans votre espace.

Je suis commerçant, je peux utiliser mon propre code ?

Non : le programme récompense les recommandations. Un commerce inscrit avec le code de son propre gérant n'ouvre pas droit à la prime. Pour recommander KEEPO à d'autres commerçants, votre espace commerçant a aussi son parrainage.
