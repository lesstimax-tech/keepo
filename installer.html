Installez Keepo
sur votre téléphone

Gardez vos points de fidélité à portée de main. L'app s'ajoute à votre écran d'accueil — aucun téléchargement depuis un store.

🔒 Si votre téléphone affiche un avertissement de sécurité (Play Protect ou « application inconnue »), c'est tout à fait normal — appuyez sur « Installer quand même ». KEEPO est une application web, sans danger.
Si rien ne se passe : ouvrez le menu ⋮ de Chrome (en haut à droite) → « Installer l'application ».
Sur Samsung Internet : menu ☰ (en bas) → « Ajouter la page à » → « Écran d'accueil ».
Astuce : ouvrez plutôt cette page dans Chrome pour une vraie application.
Toujours bloqué ? Autorisez l'installation une fois : Paramètres → Applications → votre navigateur → Installer des applications inconnues → Autoriser.

Ajoutez Keepo à
votre écran d'accueil

En 3 secondes, depuis Safari :

1
Appuyez sur Partager ⬆ dans la barre Safari
2
Faites défiler puis choisissez « Sur l'écran d'accueil »
3
Appuyez sur « Ajouter » en haut à droite
⚠️ Ouvrez cette page dans Safari (pas Chrome ni Instagram) pour pouvoir l'installer.
↓
Le bouton Partager se trouve en bas de Safari.
